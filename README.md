# Sovereign Cut 2.0 MVP

Локальный комбайн для нарезки стримов.

Что умеет MVP:

- принимает YouTube-ссылку;
- скачивает видео локально через `yt-dlp`;
- принимает таймкоды текстом;
- парсит строки вида `00:04:39 🐊 Слава Лизардии`;
- режет клипы через `ffmpeg`;
- умеет делать обычный 16:9 или вертикальный 9:16;
- создаёт `manifest.json` и `upload.csv` с заголовками/описаниями.

## Установка

```powershell
cd "D:\PYTHON\Suveren Cut 2.0"
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Если `ffmpeg` не найден:

```powershell
winget install Gyan.FFmpeg
```

После установки ffmpeg перезапусти PowerShell.

## Запуск

```powershell
cd "D:\PYTHON\Suveren Cut 2.0"
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Откроется локальное окно Streamlit в браузере.

## Формат таймкодов

```text
00:00:00 🦎 Старт рептилоидной радиостанции
00:04:39 🐊 Слава Лизардии
00:12:30 🔥 Суверенитет выше магии
```

Каждая строка становится кандидатом на клип.

Для каждой строки берётся старт по таймкоду.
Конец берётся либо до следующего таймкода, либо по лимиту максимальной длины клипа.
Для последнего таймкода берётся заданная длина, например 60 секунд.

## Папки

```text
downloads/   скачанные исходники
output/      готовые клипы
work/        служебные файлы
```

## Важно

Скачивай и режь только свои видео или материалы, на которые у тебя есть права.
